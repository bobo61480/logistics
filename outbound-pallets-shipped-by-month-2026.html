Counting Methodology

53-Foot Trailer Rule
"1 x 53", "1x53", "53'", "53 ft" etc. → 26 pallets per trailer
Explicit Count Keywords
"N PALLETS", "N PLT", "N PLTS", "N SKIDS" → face value
Single Dimension Row
"43×43×59", "Plastic Pallet", "Wooden Pallet" → 1 pallet
Excluded Rows
Status = CANCELLED · Empty rows with no date and no customer
